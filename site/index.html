Give every lesson a place.

Add exam files on GitHub ↗Read the folder guide ↗

Keep large files elsewhere

Store large scanned papers in Drive or another host and add their HTTPS links in an exam JSON record. You can link the paper and marking key separately.

New files are indexed automatically when the repository publishes. Repository access is needed to add files; public website uploads and admin approval are not connected.
